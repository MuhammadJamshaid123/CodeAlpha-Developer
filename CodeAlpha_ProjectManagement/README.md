# CodeAlpha_ProjectManagement

**Task 3: Project Management Tool** — CodeAlpha Full Stack Development Internship

## Features

- Create group projects and add team members
- Kanban board with To Do / In Progress / Done columns
- Assign tasks to team members
- Comment and communicate within tasks
- Real-time updates via WebSockets (Socket.io)
- Push notifications for assignments and comments

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Express.js + Socket.io
- **Database:** SQLite

## Setup

```bash
npm install
npm start
```

Open [http://localhost:3003](http://localhost:3003)
