# CodeAlpha — Full Stack Development Internship (M1)

All 4 tasks from the [CodeAlpha Full Stack Development Instructions](https://drive.google.com/file/d/12UT01PrGH3h92cEJ5kMJIYrQGR7RSsh9/view) are implemented in this repository.

## Projects

| Task | Folder | Port | Description |
|------|--------|------|-------------|
| 1 | [CodeAlpha_EcommerceStore](./CodeAlpha_EcommerceStore) | 3001 | E-commerce store with cart, orders, auth |
| 2 | [CodeAlpha_SocialMediaPlatform](./CodeAlpha_SocialMediaPlatform) | 3002 | Social media with posts, likes, follows |
| 3 | [CodeAlpha_ProjectManagement](./CodeAlpha_ProjectManagement) | 3003 | Trello-like PM tool with WebSockets |
| 4 | [CodeAlpha_RealTimeCommunication](./CodeAlpha_RealTimeCommunication) | 3004 | Video calls, screen share, whiteboard |

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Express.js (Node.js) — Django alternative per instructions
- **Database:** SQLite (better-sqlite3)
- **Real-time:** Socket.io + WebRTC

## Quick Start

Each project is independent. Navigate to a project folder and run:

```bash
cd CodeAlpha_EcommerceStore   # or any project folder
npm install
npm start
```
