# CodeAlpha_SocialMediaPlatform

**Task 2: Social Media Platform** — CodeAlpha Full Stack Development Internship

## Features

- User profiles with bio editing
- Create posts and view feed
- Like posts and comment on posts
- Follow/unfollow users
- SQLite database for users, posts, comments, followers

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Express.js (Node.js)
- **Database:** SQLite

## Setup

```bash
npm install
npm start
```

Open [http://localhost:3002](http://localhost:3002)
